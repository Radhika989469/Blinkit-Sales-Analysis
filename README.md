# Blinkit Sales Analysis - Power BI

## Project Overview
Analyzed Blinkit sales data to find why sales vary across locations.

## Key Insights
1. Tier 3 cities = Highest sales (0.5M+), Tier 1 = lowest
2. High fat content products = more sales in Tier 2
3. Outlet size (Medium) = best performer

## Tools Used
Excel (Cleaning, XLOOKUP, Pivot) | Power BI (DAX, Power Query)
